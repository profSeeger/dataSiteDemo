# Demo: Sharing and Visualizaing Project and Spatial Data
Last Update: January 25, 2026

This GitHub Site demonstrate a process for rapid sharing of project data and analysis without requiring a Webserver to host the information.

This project started with three GPX files that were created from data recorded during three Turkey Trot Runs in Lincoln, Nebraska in 2016 - 2018.

This repository is in progress and will be utilized in courses and workshops Professor Seeger teaches. Use outside of those venues is permissable as long as attribution is included.
